聊神桌面版 · 快速使用

适用：Windows 10/11 64 位。
直接下载 LiaoShen.exe，双击运行。无需安装 Python，无需打开 ChatGPT 或 Codex。

1. 点击桌面上的圆形机器人展开/收起；拖动后松手自动吸边。
2. 点“设置”，填 DeepSeek API Key、人设和对方语言，保存。
3. 微信打开具体单人聊天，保持窗口未最小化；点“读取微信并分析”。
4. 核对联系人、原文及“我/对方”，删除非消息行，再点确认。
5. 查看最新消息翻译、AI 洞察和三条回复；AI 洞察是推测。
6. 点击整张回复卡片复制；自行到微信粘贴、检查并发送。
7. 底部选择回复风格，可改为“短一点”或“再温柔一点”；中文意思同步更新。
8. “重新分析”沿用上次核对内容；读新消息请再点“读取微信并分析”。
9. 关闭主面板仍托盘常驻；托盘菜单“退出”才完全关闭。

确认后，核对的聊天内容、联系人名称和人设会发给 DeepSeek，产生 API 费用。
不自动发送微信消息；不保存聊天历史、联系人档案或截图。
密钥和设置使用当前 Windows 用户的 DPAPI 加密保存在：
%LOCALAPPDATA%\LiaoShenDesktop\settings.dpapi

测试状态：exe 已在 Wine 兼容层完成启动、面板展开、收起常驻及单实例检查。
