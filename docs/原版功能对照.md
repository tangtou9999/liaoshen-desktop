# 安卓 V1.9 与 Windows 1.0 体验版功能对照

核对对象：用户提供的 `LiaoShen_src_V1_9-2.zip` 内 `LiaoShen_V1_9`，以及本仓库的 Windows 1.0 体验版源码。

本次为代码和文件核对，不是功能修复或真机验收。没有改动当前 exe 或程序逻辑，也没有发布新的运行版本。不按文件数量或下面的条目数量推算“功能保留百分比”。

## 原件完整性

- 从原上传 ZIP 逐文件比对：57 个文件，0 个发生变化或丢失。安卓原工程未修改。
- `prompt_main.txt`、`prompt_analysis.txt`、`prompt_rewrite.txt`、`prompt_summary.txt`、`prompt_progress.txt`：桌面版与附件逐字节一致。
- 提示词一致不等于完整逻辑迁移：上下文拼接、设置、交互入口、记忆和结果处理仍有明显差异。

## 范围说明

最初的桌面第一版要求为一个限定功能子集，并明确暂不做“联系人记忆和档案、聊天历史、通知、语音、自动发送”。因此，下面列出相关差异是为了恢复完整产品视图，**不把原先明确排除的项目自动算作实现缺陷，也不据此自行恢复这些功能**。后续以用户最新确定的范围为准。

其他未移植项中，有些没有出现在最初的限定清单，但确实存在于安卓原版，不能用“提示词复制了”代替行为说明。特别是聊天目的、额外想法、上下文和改写选项，会直接影响用户体验及 AI 结果。

|---|---|---|---|

## 不应误认作“安卓已有而桌面删掉”的项目

安卓 V1.9 的交付说明明确记载：聊天历史**页面**、回复模板、消息提醒、语音播报、强制更新未加入。某些历史缓存和模板管理代码存在，并不等于独立历史页面或消息提醒已经完成。自动填入输入框也不等于自动发送。

这些内容以后若增加，需作为新需求或明确恢复范围处理，不能为赶进度擅自开启自动发送等行为。

## 后续修改基线

1. 原工程现有功能、输入字段和流程先由开发方查代码，用户无需重述已有功能。
2. 改某一项时，列出受影响的现有入口和上下文；未列出的现有能力不自行精简或删减。
3. 区分“源文件未改”“提示词未改”“行为已移植”“真实使用已通过”，不能相互替代。
4. 最初明确暂不做的项与本次新提出的完整迁移目标存在范围差异时，集中给出对照，不要求用户重新写全套功能描述，也不无提示地扩展持久数据/自动操作。
5. 每版报告新增、修复、仍缺失和未测试项，版本基于原版清单持续推进。
